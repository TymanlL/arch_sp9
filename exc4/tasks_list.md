# Список крупных задач для систем из ADR

## Система ставок АБС
1. **T1 - Разработка API сервиса интеграции депозитов**
   - Создание REST API для предоставления данных о ставках по депозитам
   - Разработка методов аутентификации и авторизации
   - Настройка прав доступа и ограничений использования API

2. **T2 - Разработка модуля экспорта ставок в файлы**
   - Создание модуля формирования CSV/XML файлов со ставками
   - Реализация механизма шифрования файлов
   - Разработка функционала автоматической выгрузки файлов по расписанию

## SFTP-сервер
3. **T3 - Развертывание SFTP-сервера**
   - Установка и настройка SFTP-сервера в DMZ-сегменте
   - Настройка прав доступа и учетных записей
   - Настройка журналирования и мониторинга
   - Внедрение политик безопасности

## Система кол-центра банка
4. **T4 - Разработка модуля получения ставок через API**
   - Создание API-клиента для взаимодействия с API ставок АБС
   - Реализация механизма кэширования данных
   - Настройка автоматического обновления информации каждые 15 минут

5. **T5 - Разработка интерфейса отображения ставок для операторов**
   - Проектирование и разработка UI для отображения актуальных ставок
   - Интеграция с API-клиентом
   - Настройка отображения статуса актуальности данных

## Система партнерского кол-центра
6. **T6 - Разработка модуля получения файлов с SFTP**
   - Создание SFTP-клиента для загрузки файлов
   - Разработка механизма расшифровки файлов
   - Настройка автоматической загрузки и обработки файлов по расписанию

7. **T7 - Реализация отображения ставок для операторов партнера**
   - Проектирование и разработка UI для отображения ставок
   - Интеграция с системой загрузки файлов
   - Внедрение механизма отображения статуса актуальности данных
